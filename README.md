## 🇮🇹 Italiano - Segnalazioni e Supporto PDFVC

Benvenuto nel tracker ufficiale di **PDFVC**. Questo spazio pubblico è dedicato alla raccolta di segnalazioni di bug, richieste di chiarimento tecnico e proposte di nuove funzionalità per l'applicazione desktop PDFVC.

### 🚀 Come aprire una segnalazione
Prima di aprire una nuova issue, verifica rapidamente nell'elenco delle [Issue Aperte](https://github.com/lukyba/pdfvc-bugs/issues) che il problema non sia già stato segnalato. In caso contrario:

1. Clicca su **[New Issue / Nuova Segnalazione](https://github.com/lukyba/pdfvc-bugs/issues/new)**.
2. Inserisci un **titolo chiaro e descrittivo** (es. `[Bug] Errore nel ritaglio geometrico su pagine A3` oppure `[Proposta] Supporto esportazione tabelle CSV da moduli`).
3. Compila i dettagli seguendo la checklist riportata di seguito.

---

### 📋 Checklist per una segnalazione efficace

Per permetterci di diagnosticare e correggere rapidamente il problema, fornisci sempre:

* [ ] **Versione e Build di PDFVC:** indicata nella barra del titolo o in *Aiuto → Informazioni su PDFVC Full* (es. `2.0.23-beta117`).
* [ ] **Sistema Operativo:** versione esatta di Windows (es. *Windows 11 Pro 64-bit*, *Windows 10 22H2*).
* [ ] **Passaggi esatti per riprodurre l'anomalia:**
  1. Apri un file PDF contenente...
  2. Fai doppio clic sulla pagina 2 per entrare in Anteprima...
  3. Clicca sullo strumento...
* [ ] **Comportamento atteso:** cosa avrebbe dovuto fare il programma.
* [ ] **Comportamento riscontrato:** cosa è successo in realtà (messaggi di errore, blocco, layout scorretto).
* [ ] **Log di Runtime (se applicabile):** copia le righe di errore dal menu *Aiuto → Mostra log di runtime* e incollale racchiuse in un blocco di codice:
  ```text
  [Incolla qui le righe del log di runtime]
  ```

---

### ⚠️ Importante: Privacy e Documenti Riservati
> **ATTENZIONE:** Questo repository GitHub è **pubblico e indicizzato**.
> 
> * **NON allegare MAI** documenti PDF contenenti dati personali, fatture reali, contratti commerciali, documenti d'identità o informazioni riservate.
> * Se l'anomalia si verifica solo con uno specifico documento, crea un file PDF dimostrativo con dati fittizi oppure bonifica preventivamente il documento tramite le funzioni di anonimizzazione/redazione.

---

### 💡 Proposte di Nuove Funzionalità (Feature Request)
Se desideri proporre un miglioramento all'interfaccia, una nuova operazione sulle pagine o il supporto a specifiche varianti del formato PDF, apri una issue con il prefisso `[Feature Request]` o `[Proposta]` descrivendo:
- Il caso d'uso reale e l'esigenza operativa.
- Il flusso di interazione ideale desiderato nell'interfaccia.

## 🇬🇧 English - PDFVC Issue Tracker &amp; Support

Welcome to the official **PDFVC** issue tracker. This public repository is dedicated to collecting bug reports, troubleshooting feedback, and feature proposals for the PDFVC desktop application.

### 🚀 How to Submit an Issue
Before creating a new report, please check the [Open Issues](https://github.com/lukyba/pdfvc-bugs/issues) list to see if the topic has already been addressed. If not:

1. Click **[New Issue](https://github.com/lukyba/pdfvc-bugs/issues/new)**.
2. Provide a **clear and descriptive title** (e.g., `[Bug] Crop rectangle bounds shifted on landscape pages` or `[Feature Request] Multi-column text flow support`).
3. Fill in the details following the checklist below.

---

### 📋 Effective Issue Checklist

To help us reproduce, diagnose, and fix the issue promptly, please include:

* [ ] **PDFVC Version &amp; Build:** check the window title or open *Help → About PDFVC Full* (e.g., `2.0.23-beta117`).
* [ ] **Operating System:** exact Windows edition and architecture (e.g., *Windows 11 Pro 64-bit*, *Windows 10 x64*).
* [ ] **Exact Steps to Reproduce:**
  1. Open a PDF containing...
  2. Double-click page 2 to enter Preview mode...
  3. Click the tool...
* [ ] **Expected Behavior:** what should have happened.
* [ ] **Actual Behavior:** what actually occurred (error popup, crash, visual glitch, frozen rendering).
* [ ] **Runtime Log (if applicable):** copy relevant error lines from *Help → Show runtime log* and paste them in a code block:
  ```text
  [Paste runtime log lines here]
  ```

---

### ⚠️ Critical Notice: Privacy &amp; Confidential Data
> **IMPORTANT:** This GitHub repository is **public**.
> 
> * **NEVER attach** PDF files containing sensitive personally identifiable information (PII), real financial invoices, confidential legal agreements, or proprietary data.
> * If an issue is file-dependent, reproduce it with an anonymized sample or a synthetic demo PDF.

---

### 💡 Feature Requests &amp; Enhancement Proposals
To suggest an enhancement, usability improvement, or new PDF manipulation feature, open an issue with the `[Feature Request]` prefix explaining:
- The practical workflow or business need.
- How you envision the user interaction within the UI (buttons, menus, shortcuts).
- Any relevant standards (e.g., PDF/A-4, AcroForms, CMYK prepress).
